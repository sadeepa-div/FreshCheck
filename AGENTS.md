
# FreshCheck - Android Development Instructions

## Project
FreshCheck is an AI-assisted fruit and vegetable
freshness assessment Android application.

Module: EC5208 Mobile Application Development
Team: 3 members
Deadline: December 15, 2026

## Technology Stack
- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- CameraX
- LiteRT / TensorFlow Lite
- Room Database
- WorkManager

## Current Developer
Member 1: UI/UX and Android Frontend
Branch: feature/ui-navigation

## Design
Create a premium, modern, polished Android UI.

Colors:
Primary: #176B45
Secondary: #47A875
Background: #F6F8EF
Warning: #F3B34C
Spoiled: #DB635C

Use:
- Material 3
- Reusable Compose components
- Rounded cards
- Smooth animations
- Modern icons
- Attractive gradients
- Clear typography
- Responsive layouts
- Light and dark mode
- Accessibility support

## Rules
1. Inspect the existing code before editing.
2. Use Kotlin and Jetpack Compose.
3. Preserve the current application package.
4. Work on feature/ui-navigation only.
5. Do not change AI model or database logic.
6. Use clearly labelled sample data for UI previews.
7. Make navigation and interactions functional.
8. Keep the Android project compiling.
9. Avoid unnecessary dependencies.
10. Do not commit or push automatically.
11. Never modify secrets or credentials.
12. Explain all changed files and test results.
13. Do not present visual freshness as food safety.
